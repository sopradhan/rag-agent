## 1. AGENT SPAWNING

Each agent can dynamically spawn subagents:

    parent_agent = SomeAgent()
    
    # Spawn a subagent
    child_agent = parent_agent.spawn_subagent(
        ChildAgentClass,
        "child_name",
        config
    )
    
    # Result:
    # - Child is created with parent_agent reference
    # - Child ID is registered in parent.spawned_agents
    # - Bidirectional link established
    # - Parent tracks all children

## 2. TASK DELEGATION

Parent delegates tasks to children:

    result = parent_agent.delegate_task(
        child_agent,
        "Task description",
        arg1, arg2, kwarg1=value1
    )
    
    # Inside child_agent.execute():
    # - 5 iterations of COT reasoning (Think→Evaluate→Rethink)
    # - Task execution
    # - Result returned to parent
    # - Result stored in parent.execution_results

## 3. RESULT REPORTING

Children report results back to parents:

    child_agent.report_to_parent({
        "status": "success",
        "result": {...},
        "reasoning_trace": [...]
    })
    
    # Parent receives via receive_report():
    # - Stores result in execution_results
    # - Can trigger further actions
    # - Maintains audit trail

## 4. HIERARCHICAL STRUCTURE

Agent tree with multiple levels:

    Master Orchestrator (initial)
    ├─ Pipeline Agents (Analyzer, Searcher, Filter, Ranker, Synthesizer)
    │  ├─ Analyzer
    │  ├─ Searcher
    │  ├─ Filter
    │  ├─ Ranker
    │  └─ Synthesizer
    │     ├─ RefinerSubagent (spawned on-demand)
    │     └─ ValidatorSubagent (spawned on-demand)

Each level is autonomous:
- Thinks independently (5 COT iterations)
- Spawns subagents as needed
- Delegates and waits for results
- Reports results to parent

## 5. BIDIRECTIONAL COMMUNICATION

Communication patterns implemented:

    DOWNWARD (Parent → Child):
    └─ spawn_subagent() - Create child
    └─ delegate_task() - Assign work
    
    UPWARD (Child → Parent):
    └─ report_to_parent() - Send results
    └─ receive_report() - Parent receives

Both patterns implemented in:
- DeepAgent (base_agent.py)
- LangChainSubagent (langchain_subagents.py)

## SynthesizerSubagent - On-Demand Spawning Example

The SynthesizerSubagent demonstrates on-demand helper spawning:

    def _execute(self, query: str, documents: List[Dict]) -> Dict:
        # Generate initial answer
        answer = self.llm.invoke(prompt)
        
        # SPAWN refiner agent for improvement
        refiner = self.spawn_subagent(
            RefinerSubagent,
            f"[Refiner-{self.agent_id[:4]}]",
            self.config
        )
        refined_result = self.delegate_task(
            refiner,
            "Refine and improve answer",
            answer
        )
        
        # SPAWN validator agent for quality check
        validator = self.spawn_subagent(
            ValidatorSubagent,
            f"[Validator-{self.agent_id[:4]}]",
            self.config
        )
        validation_result = self.delegate_task(
            validator,
            "Validate answer quality",
            refined_answer
        )
        
        return {
            "answer": refined_answer,
            "validation": validation_result,
            "spawned_agents": ["refiner", "validator"]
        }

This pattern enables:
- Modular responsibility (separate concerns)
- Reusable agents (RefinerSubagent can be used elsewhere)
- Efficient resource usage (spawn only when needed)
- Transparent reasoning (full trace of all agents)

## DeepAgent Methods (src/agents/deep_agent.py)

spawn_subagent(subagent_class: type, name: str, config: Dict) → DeepAgent
- Create and register a subagent
- Set parent-child relationship
- Return agent instance

delegate_task(subagent: DeepAgent, task: str, *args, **kwargs) → Any
- Invoke subagent's run() method
- Wait for completion
- Store result in execution_results

report_to_parent(result: Dict) → None
- Call parent.receive_report()
- Pass execution result up chain

receive_report(subagent: DeepAgent, result: Dict) → None
- Called by child when reporting
- Store in execution_results
- Process for next steps

get_spawned_agents() → List[Dict]
- Return list of spawned agents with metadata

get_agent_tree() → Dict
- Return hierarchical tree structure

## LangChainSubagent Methods (src/subagents/langchain_subagents.py)

Same interface as DeepAgent:
