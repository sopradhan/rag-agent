EXECUTION FLOW WITH SPAWNING
=============================

Query Processing:

1. Master Orchestrator
   └─ Create pipeline agents
   └─ Initialize: Analyzer, Searcher, Filter, Ranker, Synthesizer

2. Analyzer Agent
   ├─ spawn_subagent? No (not needed for analysis)
   ├─ Think (5 iterations): Decompose query
   ├─ Evaluate: Is decomposition valid?
   ├─ Rethink: Refine decomposition
   └─ report_to_parent() with results

3. Searcher Agent
   ├─ spawn_subagent? No (search is standalone)
   ├─ Think (5 iterations): Plan search strategy
   ├─ Evaluate: Will this find relevant docs?
   ├─ Rethink: Optimize search
   ├─ Execute: Search ChromaDB
   └─ report_to_parent() with documents

4. Filter Agent
   ├─ spawn_subagent? No (filtering is straightforward)
   ├─ Think (5 iterations): Evaluate RBAC rules
   ├─ Evaluate: Apply access level checks
   ├─ Rethink: Verify filtering logic
   └─ report_to_parent() with filtered docs

5. Ranker Agent
   ├─ spawn_subagent? No (ranking is atomic)
   ├─ Think (5 iterations): Score documents
   ├─ Evaluate: Are top-3 optimal?
   ├─ Rethink: Adjust scoring weights
   └─ report_to_parent() with ranked docs

6. Synthesizer Agent  **SPAWNS SUBAGENTS**
   ├─ Think (5 iterations): Plan answer synthesis
   ├─ Generate initial answer
   │
   ├─ spawn_subagent(RefinerSubagent)
   │  ├─ Create Refiner with parent=Synthesizer
   │  └─ Register in spawned_agents dict
   │
   ├─ delegate_task(refiner, "Refine answer", answer)
   │  └─ Refiner.execute(answer)
   │     ├─ Think (5 iterations): How to improve clarity?
   │     ├─ Evaluate: Is refined version better?
   │     ├─ Rethink: Further improvements
   │     └─ Return refined answer
   │
   ├─ spawn_subagent(ValidatorSubagent)
   │  ├─ Create Validator with parent=Synthesizer
   │  └─ Register in spawned_agents dict
   │
   ├─ delegate_task(validator, "Validate", refined_answer)
   │  └─ Validator.execute(refined_answer)
   │     ├─ Think (5 iterations): Check quality
   │     ├─ Evaluate: Quality score?
   │     ├─ Rethink: Feedback
   │     └─ Return validation results
   │
   └─ report_to_parent() with final answer + validation


AGENT HIERARCHY TREE
====================

MasterOrchestrator (Master)
├─ Analyzer (Pipeline Agent, parent=None)
│  └─ spawned_agents: {} (None spawned)
├─ Searcher (Pipeline Agent, parent=None)
│  └─ spawned_agents: {} (None spawned)
├─ Filter (Pipeline Agent, parent=None)
│  └─ spawned_agents: {} (None spawned)
├─ Ranker (Pipeline Agent, parent=None)
│  └─ spawned_agents: {} (None spawned)
└─ Synthesizer (Pipeline Agent, parent=None)
   └─ spawned_agents:
      ├─ RefinerSubagent (Helper, parent=Synthesizer)
      │  └─ spawned_agents: {} (None spawned)
      └─ ValidatorSubagent (Helper, parent=Synthesizer)
         └─ spawned_agents: {} (None spawned)

Total Agents: 7 (5 pipeline + 2 helpers spawned on-demand)
Total COT Iterations: 7 agents × 5 iterations = 35 thinking steps


COMMUNICATION PATTERNS
======================

DOWNWARD (Parent → Child):

    spawn_subagent(ChildClass, name, config)
    │
    ├─ Create child with parent_agent=self
    ├─ Register in self.spawned_agents
    └─ Return child instance
    
    delegate_task(child, task_desc, *args, **kwargs)
    │
    ├─ Call child.execute(*args, **kwargs)
    ├─ child internally calls think_and_decide()
    ├─ child executes task with 5-iteration COT
    ├─ Wait for result
    └─ Return result to parent


UPWARD (Child → Parent):

    report_to_parent(result_dict)
    │
    ├─ Check if parent_agent exists
    ├─ Call parent_agent.receive_report(self, result)
    └─ parent stores in execution_results
    
    receive_report(subagent, result)
    │
    ├─ Store result in self.execution_results
    ├─ Log receipt
    └─ Can trigger further processing


CODE PATTERNS
=============

SPAWNING PATTERN:

    parent = ParentAgent()
    
    child = parent.spawn_subagent(
        ChildClass,           # Agent class to instantiate
        "child_name",          # Name for the agent
        config                 # Optional configuration
    )
    
    # Result:
    # - child.parent_agent = parent ✓
    # - parent.spawned_agents[child.agent_id] = child ✓
    # - child.agent_id = unique UUID ✓


DELEGATION PATTERN:

    result = parent.delegate_task(
        child,                 # Child agent instance
        "Task description",    # Task name
        arg1, arg2,           # Positional args to child.execute()
        kwarg1=value1         # Keyword args to child.execute()
    )
    
    # Inside child.execute():
    # 1. Think phase: Analyze task
    # 2. Evaluate phase: Execute and assess
    # 3. Rethink phase: Refine if needed
    # 4. Returns to parent with result
    
    # Result stored in parent.execution_results


REPORTING PATTERN:

    child.report_to_parent({
        "status": "success",
        "result": {...},
        "reasoning_trace": [...]
    })
    
    # Parent receives via:
    parent.receive_report(child, result)
    # And stores in:
    parent.execution_results.append(...)


ADVANCED: RECURSIVE SPAWNING

    # An agent can spawn agents that spawn agents:
    
    master.spawn_subagent(CoordinatorAgent, "coord1")
    │
    └─ coordinator1.spawn_subagent(SpecialistAgent, "spec1")
       │
       └─ specialist1.spawn_subagent(HelperAgent, "helper1")
    
    # Full hierarchy maintained:
    master
    └─ coordinator1 (parent=master)
       └─ specialist1 (parent=coordinator1)
          └─ helper1 (parent=specialist1)


METRICS AND MONITORING
======================

Per Agent:
- agent_id: Unique identifier
- name: Agent name/role
- parent_agent_id: Parent reference
- spawned_agents: Count of children
- execution_results: List of results
- execution_log: Detailed execution history

System-wide:
- Total agents: Count including spawned
- Agent tree: Full hierarchy visualization
- Execution history: All operations logged
- Spawning relationships: Parent-child map
