1. SYSTEM ARCHITECTURE
================================================================================

LAYERED DESIGN:
  Layer 1: Master Orchestrator (agentic_orchestrator.py)
    ├─ Coordinates 5-agent retrieval pipeline
    ├─ RBAC enforcement per query
    └─ Execution tracking & logging
  
  Layer 2: Agent Pipeline (langchain_subagents.py)
    ├─ AnalyzerSubagent: Query decomposition (keywords, intent)
    ├─ SearcherSubagent: Semantic search via ChromaDB
    ├─ FilterSubagent: RBAC filtering
    ├─ RankerSubagent: Document relevance scoring
    ├─ SynthesizerSubagent: Answer generation + spawning helpers
    ├─ RefinerSubagent: Answer refinement (spawned on-demand)
    └─ ValidatorSubagent: Quality validation (spawned on-demand)
  
  Layer 3: Storage (vector_store.py + sqlite_storage.py)
    ├─ ChromaDB: 51 indexed documents, semantic search
    ├─ SQLite: Metadata, RBAC rules, access levels
    └─ HybridRetriever: Combined search with filtering

  Layer 4: Base Agent (deep_agent.py)
    ├─ Parent-child relationships tracking
    ├─ Agentic spawning & delegation
    ├─ Chain-of-thought reasoning (5 iterations)
    └─ Execution history per agent

6. AGENTIC SPAWNING IN ACTION
================================================================================

SYNTHESIS PIPELINE:
  SynthesizerSubagent (parent)
    ├─ spawn_subagent(RefinerSubagent, "[Refiner]")
    │  └─ Task: Improve answer clarity
    │     Result: Refined answer
    │
    └─ spawn_subagent(ValidatorSubagent, "[Validator]")
       └─ Task: Validate quality
          Result: Quality score

PARENT-CHILD COMMUNICATION:
  Parent → Child:
    synthesizer.spawn_subagent(RefinerSubagent, "[Refiner]")
    synthesizer.delegate_task(refiner, "refine_answer", answer)
  
  Child → Parent:
    refiner.report_to_parent({"refined": answer, "score": 0.95})
    synthesizer.receive_report(refiner, result)
